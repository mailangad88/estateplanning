## How to use this template

We are sorry for your loss. An executor is a fiduciary, which means you handle other people's money and may be asked to show exactly what you did with it. A clean ledger answers most questions before anyone asks. Print these tables or copy them into a spreadsheet. Fill them in as things happen, not months later. Whether a court accounting is required, and in what form, varies by state and by estate. Beneficiaries often ask for one even when the court does not.

## Set up before you record anything

- [ ] Open a separate estate bank account using the estate's tax ID number (EIN)
- [ ] Keep one folder, paper or digital, for every receipt and statement
- [ ] Never pay estate bills from personal money without writing it down as a reimbursement
- [ ] Use the same date format throughout

- **Estate name:** ____________________
- **Date of death:** ____________________
- **Estate EIN:** ____________________
- **Estate account bank and last four digits:** ____________________
- **Opening date of account:** ____________________

## Part 1: Starting inventory

List what the person owned on the date of death, with the value on that date. Date-of-death values matter for taxes. Beneficiaries who inherit property may get a new tax basis, so ask a tax professional how to document it.

| Asset | Owned in whose name | How value was found | Date-of-death value | Passes by will or by other means |
|---|---|---|---|---|
| Checking account | | Bank letter | | |
| Home | | Appraisal | | |
| Vehicle | | Valuation guide | | |
| Brokerage account | | Statement | | |
| Personal items | | Estimate or appraisal | | |
| | | | | |

Only property that passes through the estate belongs in the ledger. Accounts with a named beneficiary usually pass directly. Keep a separate note of them for completeness. See [probate vs non-probate assets](/learn/probate/probate-vs-non-probate-assets).

## Part 3: Money paid out

Record every payment, even small ones.

| Date | Paid to | Reason | Check or reference number | Amount | Receipt saved? |
|---|---|---|---|---|---|
| | Funeral home | Funeral costs | | | |
| | Court | Filing fee | | | |
| | Utility | Final bill | | | |
| | Attorney | Legal fees | | | |
| | Tax authority | Final tax payment | | | |
| | Executor | Reimbursement | | | |

Group the payments into categories so the final summary is easy.

- [ ] Funeral and burial costs
- [ ] Court and administration costs
- [ ] Legal and accounting fees
- [ ] Taxes
- [ ] Debts and creditor claims
- [ ] Upkeep of property, such as utilities, insurance and repairs
- [ ] Executor compensation, if your state and the will allow it

Executor compensation is regulated by state law and the will. If you plan to take any, write down how you calculated it and tell beneficiaries up front.

Do not pay a debt just because a collector calls. Check that the claim is valid and was made on time. See [what happens to debt when someone dies](/learn/probate/dealing-with-debts-in-probate).

## Part 5: Distributions

Record each distribution as it is made, and ask the recipient to sign a receipt.

| Date | Beneficiary | What was given | Value | Signature received |
|---|---|---|---|---|
| | | | | |

Sample receipt wording:

"I, ____________, received ____________ from the estate of ____________ on ____________. I acknowledge this as part of my share."

- **Signed:** ____________________
- **Date:** ____________________

Make distributions only after an attorney confirms that claims and taxes have been covered. An early distribution can leave an executor personally responsible if a bill appears later.

## Part 6: Final accounting summary

At the end, copy your totals here. This is a plain summary. A court may require its own form.

- **Total assets at the start:** ____________________
- **Plus income and sale proceeds during administration:** ____________________
- **Total available:** ____________________
- **Less expenses paid:** ____________________
- **Less debts and taxes paid:** ____________________
- **Less distributions made:** ____________________
- **Balance remaining (should be zero or held for a stated reason):** ____________________

The balance on your ledger should match the bank balance. If it does not, find the difference before sending anything to the court or the family.

## Monthly habits

1. Reconcile the estate bank statement against your ledger once a month.
2. Scan or photograph receipts the day you get them.
3. Write a one-line note for any unusual payment.
4. Send beneficiaries a brief update on a regular schedule.
5. Keep records for as long as your attorney advises, which is often several years after closing.

## When to talk to an attorney

- The estate is large, owes tax, or owns a business or rental property
- A beneficiary asks for a formal accounting and you are unsure what to include
- You want to pay yourself for your time
- Your numbers do not balance
- A beneficiary suspects mismanagement
- You are considering a distribution before the claim period ends
