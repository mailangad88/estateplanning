## How to use this checklist

Find your will, read it start to finish, and tick each item. A will does not expire, but life moves on. People die, move, divorce or change. Marking up a signed will by hand can cause trouble, so write notes on a separate copy instead. For broader reviews see [updating your estate plan](/guides/updating-your-estate-plan).

## Step 1: Find the right document

- [ ] I located the original signed will, not only a copy.
- [ ] The date at the end is: ____________
- [ ] It is the latest version. Any later will or codicil is attached.
- [ ] I know where the original is kept: ____________
- [ ] I know which state's law applied when it was signed: ____________

## Step 2: Life changes since signing

- [ ] Marriage, divorce or separation
- [ ] Birth or adoption of a child or grandchild
- [ ] Death of a spouse, child or named beneficiary
- [ ] A child who has grown up, or now has special needs
- [ ] A family member who has become estranged
- [ ] A significant change in health
- [ ] A new home, a sale or a move to another state
- [ ] New business, inheritance or retirement
- [ ] A change in the tax laws or the size of my estate

Divorce can cancel gifts to an ex-spouse in many states, and it can do so in ways that surprise people. Rules vary by state. Ask an attorney how your state treats a divorce, a marriage and later-born children.

## Step 3: Check every named person

| Role | Name in will | Still living? | Still suitable? | Contact current? |
|---|---|---|---|---|
| Executor | | | | |
| Backup executor | | | | |
| Guardian for minor children | | | | |
| Backup guardian | | | | |
| Trustee (if trust created by will) | | | | |
| Each beneficiary | | | | |

For guardians, ask the same question twice: would this person still be willing, and would the child still be well cared for? See [guardianship for minor children](/guides/guardianship-for-minor-children).

## Step 4: Check the gifts

- [ ] Every item or sum I left is still something I own.
- [ ] Gifts of fixed dollar amounts still make sense with my current wealth.
- [ ] The residuary clause, which says who gets everything left over, still matches my wishes.
- [ ] Anyone who was left out is left out on purpose.
- [ ] Gifts to a child who is now an adult, or who needs government benefits, are still structured sensibly.
- [ ] A gift to a person who died has a stated alternate. If not, the gift may lapse.

## Step 5: Check what the will does not control

Many assets pass outside the will. A will is overridden by joint ownership, beneficiary forms and trust ownership. Compare:

| Life insurance | | |

## Step 6: Check the signing and practical details

- [ ] The will was signed and witnessed in line with the law at that time. See [what makes a will valid](/guides/what-makes-a-will-valid).
- [ ] A self-proving affidavit was attached, if my state allows one.
- [ ] Pages are in order, with no staple holes, missing pages or handwritten edits.
- [ ] No important digital assets, pets or personal items are left without a plan.
- [ ] The will does not give instructions on funeral wishes that nobody will read in time. Use a separate note.

## Signs you should replace it

- It was signed in a different state and you have since moved.
- A named executor, guardian or main beneficiary has died or is no longer suitable.
- There has been a marriage, divorce or new child.
- You have changed more than one or two items.
- It was a do-it-yourself form and you are unsure it was signed correctly.
- It is long out of date, with details that no longer fit.

A short codicil, a signed amendment to a will, can fix one narrow item. Many attorneys prefer a new will when changes are several, because patched documents are easy to misread.

## What to bring to your attorney

- [ ] The will and any codicils
- [ ] A list of assets with how each is titled
- [ ] Copies of beneficiary forms
- [ ] Your notes from Steps 2 to 5
- [ ] Names and addresses for each person you plan to name

## When to talk to an attorney

- Your marital status or family has changed.
- You have moved to a new state.
- You own a business or property in more than one state.
- A beneficiary now has special needs, debts or addiction concerns.
- You are not certain the old will was signed validly.
