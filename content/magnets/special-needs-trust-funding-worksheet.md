## How to use this worksheet

A special needs trust only helps if it holds enough money, and that money has to arrive in the trust. Work through the steps in order. The numbers are estimates. Rounding is fine. Bring the finished page to your attorney and financial adviser. Rules vary by state and benefit program.

## Step 1: Estimate the yearly gap

Benefits like SSI and Medicaid cover basics. The trust usually pays for things benefits do not. Fill in what you expect per year, in today's dollars.

| Need | Yearly cost | Covered by benefits | Trust must pay |
|---|---|---|---|
| Housing, if not fully covered | | | |
| Extra support staff or respite | | | |
| Therapies and equipment | | | |
| Transportation | | | |
| Recreation, travel, hobbies | | | |
| Phone, internet, clothing | | | |
| Care manager or advocate | | | |
| Trustee and tax costs | | | |
| Total | | | |

- **Total yearly amount the trust must pay:** ______________________

A trust does not give cash to your loved one in a way that replaces benefits. It generally pays vendors or buys goods and services directly. Ask your attorney how your state treats payments for food and shelter.

## Step 2: Turn it into a lifetime number

- **Current age of your loved one:** ______________________
- **Years of expected life, a planning guess you and your doctor choose:** ______________________
- **Yearly gap from Step 1:** ______________________
- **Years multiplied by gap:** ______________________

Then adjust. Prices rise over time, but invested money can also grow. A financial professional can model both. Many families aim to fund the gap partly by growth and partly by principal.

- **Planning figure after adjustment:** ______________________

| Source | Amount | Goes to the trust how? |
|---|---|---|
| Savings and investments | | By will, trust or retitling |
| Home equity | | Sale or inheritance |
| Life insurance (yours) | | Name trust as beneficiary |
| Life insurance on a second parent | | Name trust as beneficiary |
| Retirement accounts | | See Step 5 |
| ABLE account | | Separate from trust |

- **Total available:** ______________________
- **Gap between planning figure and total:** ______________________

## Step 4: Consider life insurance

Many parents cover the gap with life insurance because it pays at the moment funds are needed, and costs are known in advance. A joint policy that pays after the second parent dies, often called second-to-die, is another option. Cost depends on age and health.

- [ ] Compare term and permanent insurance
- [ ] Check how long you need coverage
- [ ] Name the trust, not your loved one, as beneficiary
- [ ] Confirm the trust exists before it is named
- [ ] Use the [life insurance needs tool](/tools/life-insurance-needs) for a starting estimate

## Step 5: Fix beneficiary forms

The most common error is leaving money directly to the person with a disability on a form. That can interrupt benefits.

| Account | Current beneficiary | Should be |
|---|---|---|
| Life insurance 1 | | Trust |
| Life insurance 2 | | Trust |
| 401(k) or 403(b) | | Review with attorney |
| IRA | | Review with attorney |
| Annuity | | Review with attorney |
| Bank accounts with payable-on-death | | Trust or other |

Retirement accounts have special tax rules when a trust is named, so ask a tax professional and attorney. A trust written for a person with a disability may receive favorable treatment, but the details are technical. See [beneficiary designations](/guides/beneficiary-designations).

- [ ] Request fresh copies of each form
- [ ] Name a backup beneficiary
- [ ] Keep confirmations with the trust

## Step 6: Tell relatives how to give

Grandparents and others often want to help. A gift directly to your loved one can count as a resource. Give them a simple note:

"Please do not leave money directly to [Name]. It may affect benefits. If you wish to help, we can give you the name of the trust and have your attorney include a gift in your will or beneficiary forms."

## Step 7: Check who runs the trust

- **Trustee:** ______________________
- **Backup trustee:** ______________________
- **Who advises the trustee on care:** ______________________
- **Who receives what remains after your loved one dies:** ______________________

Some trusts must repay Medicaid at the end. Others, funded by a third party like a parent, often do not. Ask which type you have. See [special needs trusts](/guides/special-needs-trusts).

## When to talk to an attorney

- You are deciding between a third-party trust and a self-settled trust
- Your loved one already owns money, an award or a settlement
- You want a trust named on retirement accounts
- You are unsure whether the trust can pay for housing
- The trust is signed but has not been funded
